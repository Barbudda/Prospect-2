# Personas

## Primary user: The Solo Founder
- Role: Founder building and selling an AI guest assistant for Airbnb hosts
- Technical level: Intermediate — can configure API keys, run npm commands
- Goal: Find 50 contactable STR businesses per week to cold outreach
- Main pain: Wastes hours doing manual Google searches with no scale
- Needs: Fast, automated, real data, CSV export, no maintenance burden
- Not a developer — wants a working tool, not fragile code to babysit

## Target leads (who the founder is looking for)
1. Airbnb concierge companies — professional check-in/checkout operators
2. Property managers — manage 5 to 50 Airbnb units for owners
3. Vacation rental agencies — seasonal rental specialists
4. Direct booking property owners — own website, bypassing OTAs
5. Gîte / villa / holiday rental operators — rural and coastal rentals
6. Co-hosts and Superhost consultants
7. Real estate agencies offering seasonal rental management services
